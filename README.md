# Titanic Dataset – Data Cleaning

## Project Overview
This project focuses on identifying and cleaning data quality issues in the Titanic passenger dataset using Python and Pandas.

## Dataset
- Dataset: Titanic Passenger Dataset
- Source: https://github.com/datasciencedojo/datasets/blob/master/titanic.csv
- Tools: Google Colab, Python and Pandas

## Data Quality Checks
- Checked missing values.
- Checked duplicate records.
- Inspected data types.
- Checked inconsistent text values.

## Cleaning Steps
- Handled missing Age values using the median.
- Handled missing Cabin values using "Unknown", if retained.
- Checked and removed exact duplicate rows.
- Removed extra spaces from text columns.
- Converted Age and Fare to numeric data types.
- Converted Sex into a dummy variable using Pandas, if included in the final notebook and dataset.

## Files Included
- titanic_cleaned.csv — cleaned dataset.
- Task1_Data_Cleaning.ipynb — Python notebook.
- data_quality_report_before.csv — original audit report, if included.
- data_quality_report_after.csv — final audit report, if included.

## Outcome
The dataset was inspected, cleaned and checked after processing. The notebook documents the data cleaning workflow.
